# RAITON website

Corporate website for RAITON L.L.C-FZ, a Dubai trading company working in general trading, offshore crude oil trading and logistics. Client project.

**Live:** https://raiton-website-azure.vercel.app

## Stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, deployed on Vercel.

## Notes

- **Two languages.** English at `/`, Turkish under `/tr/`. Both share one typed dictionary in `lib/i18n.ts`; `proxy.ts` sets the locale header so the root layout can emit the correct `<html lang>`.
- **SEO.** Per-page metadata and Open Graph tags, plus `sitemap.ts` and `robots.ts` generated by Next.js.
- **Content.** Only facts from the client brief are used; missing business details are left out rather than invented. Image sources are listed in `ASSET_SOURCES.md`, and the launch checklist is in `PRODUCTION_CHECKLIST.md`.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
npm run lint
npm run typecheck
npm run build
```
